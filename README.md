# 🗺️ MiTecmm · Campus Map & Directory

Sistema de navegación interactivo y directorio docente para el Instituto Tecnológico Superior de Zapopan (TecMM). Permite explorar planos arquitectónicos multicapa, buscar aulas, ubicar profesores y consultar el mapa general del campus.

---

## 🚀 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado en tu computadora:

* **Node.js** (versión LTS recomendada, v18 o superior): [Descargar Node.js](https://nodejs.org/)
* **Git**: [Descargar Git](https://git-scm.com/)
* **Gestor de paquetes**: `npm` (incluido con Node.js) o `yarn` / `pnpm`.
* **Expo Go** *(Opcional)*: Aplicación móvil para probar en dispositivos físicos Android o iOS.
